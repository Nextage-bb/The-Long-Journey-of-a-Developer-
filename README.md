 🏔️ Landscapes: Switzerland & Oregon

Hey, I'm Pedro! 👋 This is a little website about two places that caught my eye: **Switzerland** and **Oregon**.

Mountains, bridges, sunsets, and yes, there are cows. 🐄 No, I'm not sorry.

🔗 **See it live:** https://nextage-bb.github.io/The-Long-Journey-of-a-Developer-/

## 👀 What's inside

- A Switzerland section with a fresh green-and-cream vibe 🌿
- An Oregon section with earthy, sunset-ish colors 🌅
- Photos, looping videos, and little "local culture" cards that float up when you hover over them
- A header menu (the links don't go anywhere yet, we'll get there)

## 🛠️ Built with

- **HTML** and **CSS**, hand-written, no frameworks
- **Inter** font via Google Fonts
- A lot of Googling and trial and error 😅
